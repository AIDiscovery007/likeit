# Likeit

macOS 网易云音乐的 Raycast `like` 命令：确认当前正在播放的歌曲后添加喜欢；已经喜欢则保持原状。

**本机 Raycast 首次收藏、重复执行及暂停拒绝路径已由协调者实测通过。** 输入 `like`，选择 **Like Current Track** 并回车即可使用。完整兼容矩阵仍有未验证项，见 [独立验收记录](docs/review-2026-10-11.md)。支持范围是网易云，不自动识别所有发声 app。

## 使用

在 Raycast 搜索 `like`，选择 **Like Current Track**。也可以在 Raycast 设置中手动配置 `like` alias 或全局快捷键；搜索关键词不会自动创建别名。

网易云需要已运行、正在播放，且歌曲身份、播放及喜欢状态均能确认。命令不启动播放器、不切换播放、不激活网易云或发送快捷键。已喜欢只提示；读不到身份、来源不是网易云、暂停或换歌时停止。另一条命令正在执行时提示处理中。

成功提示表示同一播放条目的客户端菜单已确认喜欢，不保证云端同步。出现“结果未确认”时请在网易云检查；命令不会重试点击。未登录、离线或不支持收藏的内容可能无法确认结果。

在 **Raycast Settings → Extensions → Likeit → 收藏成功动效** 选择模式：

- **跟随系统（默认）**：仅 macOS 关闭“减少动态效果”且能确认该设置时播放彩带。
- **始终播放**：仅对 Likeit 忽略系统“减少动态效果”，不更改系统设置或其他 app。
- **关闭**：只显示文字提示，不读取动画策略或启动彩带。

三种模式都只为已确认的新收藏庆祝，已喜欢或结果未确认时不庆祝。无法读取模式时按关闭处理。彩带故障不会改变收藏结果或重试收藏。本次未发布本地版以三态选择替代旧 checkbox，不迁移旧 checkbox 的值；升级后采用新默认“跟随系统”，可在上述设置中重新选择。可见动画和真实收藏联动仍待桌面验收。

## 权限

正式命令通过原生辅助功能接口读取菜单并执行语义明确的 Like。需要在“系统设置 → 隐私与安全性 → 辅助功能”检查 Raycast 相关授权。命令只检测权限，不弹出授权申请或修改系统设置。本机现有权限下的 Raycast 路径已成功；没有更改系统授权，首次授权流程及权限撤回后的体验仍未验证。开发终端可读不代表另一台机器上的 Raycast 已获授权。

正式路径不需要 System Events 自动化授权。旧的 `assets/netease-state.jxa` 仅为只读诊断脚本，使用它可能另需终端的辅助功能／自动化权限，其结果不能代替正式入口权限验证。

## 安装与开发

通过 Raycast 导入本项目或在装有 Node.js、npm、Raycast 的开发环境运行：

```sh
npm install
npm run dev
```

`assets/native` 已包含控制器、MediaRemote framework、Perl 入口及许可证。普通命令只运行随包二进制和 macOS 自带 Perl，不下载或编译代码，用户无需安装 Xcode、CMake 或 Homebrew。

彩带和 Reduce Motion 使用独立的随包 helper，不访问音乐、不增加辅助功能／录屏／自动化授权。彩带依赖固定 ConfettiSwiftUI 3.0.0（`9ae5bc2ce2149980884d4612321c3a266d6bf82c`），原始源文件及 MIT 许可保留在 `vendor/ConfettiSwiftUI`；两处获批时长补丁仅作用于构建副本，来源和产物摘要记录于 `assets/native/BUILD.json`。

修改原生源码的开发者使用 Python 3 和 Apple Command Line Tools 重建：

```sh
python3 scripts/build-native.py
npm run build
npm run lint
```

构建脚本先校验固定上游源码，编译 arm64 / x86_64，合并通用二进制并 ad-hoc 签名。来源为 `ungive/mediaremote-adapter` 的 `797729d9b16316dc313844476c153d7a107ca0df`，BSD-3-Clause 许可随包保留；来源摘要在 `vendor/mediaremote-adapter/SOURCE.json`，构建命令及二进制摘要在 `assets/native/BUILD.json`。构建时不运行媒体命令或 TestClient。两架构编译通过不代表 Intel 实机验证，ad-hoc 签名不代表公证或正式发布签名。

开发者不编写、修改或运行测试。固定行为验收、并发与异常退出检查、真实收藏由协调会话负责；交接规则见 `docs/handoff.md`。

## 身份、安全边界与限制

身份键由真实媒体会话的 bundle ID、PID、contentItemIdentifier、曲名、歌手、专辑、时长组成，只比较本次命令内的播放条目。它不是网易云歌曲库 ID，不跨命令缓存，也不保证跨重播或客户端重启稳定。字段缺失或变化会保守拒绝，不能用歌名降级收藏。

每次读取以及动作前均执行媒体 → 菜单 → 媒体夹取，核对同一身份、PID 和播放状态。仅唯一启用的 Like 菜单可触发 AXPress。每个命令最多发出一次动作；执行后仍需相同歌曲的已喜欢状态才确认成功。读取与菜单动作无法原子绑定，最后检查后恰好换歌仍有窄竞态，不能承诺绝对不会错曲。

控制器对固定锁文件持有非阻塞独占 `flock`，覆盖整个流程及确认阶段。进程退出自动释放，不删除锁文件；锁描述符不会传给媒体子进程。单次媒体读取限制四秒、64 KiB 输出；命令总期限 25 秒，超时终止整个进程组。写入或确认阶段失联显示结果未确认。

已验证本机 macOS 26.6.2、网易云 3.1.13 的真实收藏、重复执行、暂停拒绝，以及原生会话并发锁、超时和异常退出后的恢复。冻结的 28 条行为检查未修改且全部通过。最小化和关闭窗口后的调用返回已喜欢，但焦点、Space 和窗口状态的完整证据仍不足；中文菜单、权限变更、其他播放器抢占、账号、网络及 Intel 真机等范围仍未验证，不能据此宣称全矩阵验收通过。MediaRemote 为私有系统接口，系统更新可能使其失效；失败时拒绝收藏。设计与证据见 `docs/native-design.md`、`docs/identity-research.md`、`docs/review-2026-10-11.md`。

## 沉浸音乐桌面

Raycast 搜索 **Likeit** 打开新菜单，选择 **沉浸模式**。独立的 Likeit Desktop app 覆盖当前指针所在显示器；右上角 **退出 · Esc**、Esc 或 Cmd+Q 可立即退出，不改变音乐播放。菜单中的 **收藏当前歌曲** 调用原收藏命令，原来的 `like` 快捷路径继续保留。

沉浸桌面要求 macOS 14.2+，原收藏仍支持 macOS 13+。扩展设置的 **沉浸桌面动效** 提供跟随系统、始终播放、关闭三种模式，独立于收藏彩带设置。桌面读取真实曲目信息、播放进度和所选来源的歌词；允许动效及音频权限后，音膜与光环响应网易云实际低中高频能量。默认网易来源按曲名、完整艺人、专辑和时长严格唯一匹配网易公开接口；无可靠匹配、空歌词或网络失败时保留歌曲信息，不展示示例歌词。

开发构建：`python3 scripts/build-desktop.py`，只构建桌面 app，不重建收藏 helper；普通用户不需要 Xcode 或运行编译器。产物位于 `assets/native/Likeit Desktop.app`，同时包含 arm64 和 x86_64，默认采用本地 ad-hoc 签名，也支持下述显式签名身份；双架构编译不代表 Intel 实机已验证。

桌面独立读取固定版本 MediaRemote adapter 的完整事件流，每 2 秒以两次快照复核来源和身份；不使用收藏锁或写入控制器。进度以微秒时间锚换算到单调时钟，暂停冻结，超过 5 秒没有有效快照停止推进。网易接口每次请求最长 5 秒、响应最多 1 MiB，整轮最长 15 秒；无 Cookie、URL 凭据存储、HTTP 磁盘缓存或音频上传。成功解析的歌词单独保存到本地歌词缓存，退出重开可直接复用，范围和清理方法见下文。Apple 私有媒体接口和网易公开接口可能随版本变化。

首次进入且网易正在播放、动效开启时，macOS 可能请求 **Likeit Desktop** 的系统音频访问权限。用途仅为实时分析网易云进程的音频：不采麦克风、不采其他 app、不录制、不落盘、不上传音频，也不改变输出设备或播放状态。尚未收到样本时显示等待音频；已开始采集后短暂断流会保持静态，并在同一会话恢复 PCM 时继续律动。启动或设备重建失败不会被当成权限拒绝，也不会因状态刷新自动重试。桌面会提供 **重试音频** 按钮，仅在当前可见、正在播放且动效允许时重新核实来源并尝试一次；连续点击合并，健康采集不重建，退出后不再启动。歌词和退出始终可用。系统统一日志的 `com.likeit.desktop` / `audio` 分类记录失败阶段与 OSStatus 或无效结果原因，不记录音频、歌曲信息或凭据。

**关闭**动效，或**跟随系统**且 macOS 开启“减少动态效果”，不会启动采集。切到其他 app 或弹出 Raycast 时，只要桌面仍有可见区域，就继续采集和刷新歌词。系统报告窗口隐藏、最小化或完全遮挡时停止采集并降低歌词刷新频率；重新可见后，在播放与动效条件仍满足时恢复，无需成为前台应用。暂停、静音或过期输入回到静态。音频仅有 2048 帧短内存缓冲，FFT 分析和显示目标 30fps，真实延迟及设备兼容性仍需实机测量。歌词不会因关闭动效而关闭。

默认本地包使用 ad-hoc 签名，其 designated requirement 随构建及架构的代码哈希变化，不能保证更新后沿用隐私授权。移动安装路径或重新构建后系统可能要求重新授权；音频启动失败也可能是系统 tap 或设备异常，不能据此判断用户拒绝权限。`com.apple.security.device.audio-input` 用于 hardened runtime 的 Core Audio 访问，不代表产品访问麦克风。系统授权始终由用户决定；收藏所需的辅助功能权限与桌面音频权限是两条独立路径。


已有固定代码签名身份的开发者，可显式选择该身份（建议使用其证书指纹）：

```sh
LIKEIT_DESKTOP_SIGNING_IDENTITY='YOUR_EXISTING_CODE_SIGNING_IDENTITY' python3 scripts/build-desktop.py
```

同一身份用于 framework 和 app，并验证签名；空值、`-` 或不可用身份会使显式配置构建失败，不会退回 ad-hoc。不设置该变量时仍支持原开发构建，并打印授权延续风险提示。构建清单记录实际签名类型及 app/framework 各架构的 designated requirement。脚本不创建或导入证书、不修改钥匙串信任、不重置 TCC，也不启动 app。固定身份不等于公证；跨版本授权保持仍需用同一身份的两个真实构建验证，不能承诺永久免授权。

桌面发布前的本地构建顺序：

```sh
python3 scripts/build-desktop.py
npm run build
npm run lint
```

原生脚本先核对已固定 adapter 的摘要，再编译桌面；版本、源码及包内文件摘要记录于 `assets/native/DESKTOP-BUILD.json`。app 自带只读 adapter 与许可证，通过实际 bundle 位置寻找资源，不依赖开发目录。桌面内的 framework 使用无符号链接的平铺布局，构建阶段调整库标识并签名，避免 Raycast 复制时把版本链接改成开发目录的绝对链接；安装后无需重签名。`npm run build` 会更新本机 Raycast 的扩展产物，应避免与另一个验收会话同时运行。项目尚未 push、发布或公证。

歌词搜索会将当前曲名及完整艺人字符串发送给 `music.163.com`，随后仅请求唯一匹配候选的详情和歌词；不发送音频、账号数据或播放器 UUID。多艺人只接受完整集合或完整精确的 ` / ` 拼接，不猜 `/` 的含义，不删版本后缀；因此部分歌曲会显示暂无可用歌词。搜索结果内唯一不等于全曲库原曲身份的保证。

本轮开发完成只表示产品实现与构建可交付。I1/I2 的实际 Raycast 进入、Esc/Cmd+Q 退出、重复进入单实例，以及一首歌曲的真实歌词、播放推进和暂停冻结已由协调者确认；最终版本音频授权、真实节奏、拖动/换曲、拒绝与撤权、长句、多显示器、设备热切换、Intel/macOS 14.2 和十分钟性能仍需协调者独立验收。未提供这些项目的实测结论。

## 可选：社区歌词（AMLL / LRCLIB）

在 **Raycast Settings → Extensions → Likeit → 沉浸桌面歌词来源** 选择 **社区歌词（AMLL / LRCLIB）**，再从 Likeit 菜单打开沉浸模式。已打开的桌面也会取消旧请求、清空旧歌词并按当前选择重新加载。默认仍为 **网易歌词**；缺失或无效选项按默认处理。社区模式不读取官方配置、token 或私钥，不需要新增系统权限。

社区模式先通过网易公开 search + detail 两次核对完整歌曲信息，确认唯一数字歌曲 ID，再请求 AMLL。不会把播放器 UUID 或曲名当作网易 ID。AMLL 响应必须包含同一网易 ID 和合法 TTML；失败时独立查询 LRCLIB，并再次严格核对完整曲名、艺人字符串、专辑和时长（差值最多 1 秒）。不会移除 Live、Remix 等版本词，也不会采用模糊搜索第一条。

- **AMLL**：支持真实逐词时间、逐行时间和行内中文翻译，保留原文空格；背景人声和音译不混入主句。当前仅显示行内 `x-translation`，暂不展示 Apple `head/metadata` 中按 key 关联的翻译。不支持或无效的结构会进入 LRCLIB 后备。
- **LRCLIB**：有同步 LRC 时逐行显示；只有纯文本时标注“未同步歌词”，静态显示可滚动全文；明确纯音乐且没有冲突正文时显示“纯音乐”。v1 不消费 LRCLIB 的 YAML `lyricsfile` 逐词数据。
- 逐词亮度跟随真实词时间，逐行歌词不推算词时间。暂停冻结、seek 重新定位；无有效进度或快照过期时清除同步高亮。关闭装饰动效不关闭歌词高亮。

状态栏标注来源和匹配方式。AMLL 的网易 ID 关联由社区维护，LRCLIB 的元数据匹配也不是声音指纹；成功获取不保证歌词或同步完全准确。两源均不可用时显示暂不可用，不用示例歌词填充，歌曲信息、音频功能和退出仍可用。

请求只使用固定 HTTPS 端点：`music.163.com` 接收曲名和艺人搜索词及已验证 ID；`api.amll.dev` 仅接收已验证网易 ID；`lrclib.net` 接收曲名、完整艺人、专辑和时长。不发送播放器 UUID、音频、账号凭据或 Cookie，不跟随重定向。每请求最长 5 秒、响应最多 1 MiB，整轮加载最多 15 秒。429 按 `Retry-After` 冷却；没有有效冷却值时等待 60 秒，同一桌面进程内重开也不会绕过。不自动轮询或无限重试，可重开或换源发起新一轮加载。

社区歌词成功后保存解析文档，包含来源、翻译、逐词时间和原始文本范围；纯文本和纯音乐状态也可复用。社区模式不新增 npm / Swift 第三方依赖，不引入 AMLL Web 播放器。

来源与许可：[AMLL 数据库](https://github.com/amll-dev/amll-ttml-db)、[AMLL API](https://github.com/amll-dev/amll-ttml-api)、[LRCLIB](https://github.com/tranxuanthang/lrclib)。AMLL API 软件采用 MIT / Apache-2.0，LRCLIB 软件采用 MIT；AMLL 数据库区分外来数据的原协议和提交者自主编写部分的 CC0。软件许可不等于全部歌词拥有统一的使用授权。

社区功能的真实桌面显示、长句、逐词同步、seek、换源和退出由协调者另行验收，构建通过不能替代这些实测。多任务开发时，可使用 `npx ray build --output ./node_modules/.cache/likeit-community-build --exit-on-error` 将扩展构建留在本 worktree，避免默认构建更新正在验收的 Raycast 安装。

## 本地歌词缓存与来源

沉浸桌面会把成功的网易公开歌词、网易官方歌词和社区歌词保存到 `~/Library/Caches/Likeit/Lyrics`。再次打开同一首歌时直接显示并标注“本地缓存”，命中不发送搜索、详情或歌词请求，也不显示网络匹配状态。播放器重启引起 PID 或临时歌曲 key 变化，不会让已有缓存失效。

缓存按完整曲名、艺人、专辑、精确时长、可信网易 ID 输入和所选来源策略区分；Live / Remix 版本词不会被移除。官方缓存还按当前合法配置的应用 ID、token、设备信息、私钥和歌词模式的 SHA-256 摘要隔离；配置变更、移除或失效后不会复用旧官方内容。缓存只保存解析歌词和来源提示，不保存配置原文、凭据、签名或官方命令清单。

每项从获取成功起有效 **30 天**，读取不续期。所有来源合计最多 **200 项 / 20 MiB**，单项最多 **1 MiB**，容量不足时淘汰最久未访问的条目。目录仅本人可访问（0700），文件仅本人可读写（0600），通过原子替换写入，不跟随缓存文件符号链接。错误、空内容或未确认匹配不会缓存；损坏、过期、未知格式或不可写目录不会阻止正常网络获取。

退出会清理内存和请求，保留磁盘歌词。要清空缓存，先退出 Likeit Desktop，再在 Finder 的“前往文件夹”打开 `~/Library/Caches/Likeit`，删除其中的 `Lyrics` 文件夹；下一次打开会重新匹配。

来源与后备策略保持明确：

- **网易歌词（默认）**：没有官方配置时走网易公开歌词；有合法配置时走网易官方歌词。官方配置或授权失败会明确提示，不自动切换社区来源。
- **社区歌词**：严格确认网易 ID 后优先 AMLL，AMLL 不可用时由 LRCLIB 独立核对完整元数据；LRCLIB 依次采用逐行 LRC、纯文本或明确纯音乐。两源均不可用时保留歌曲信息并提示原因。

缓存不会改变这些来源选择，也不会把一个来源的成功内容冒充另一个来源。

## 可选：网易官方歌词配置

选择“网易歌词”来源且没有配置时继续使用原公开歌词路径。有自己的应用权限、access token、PKCS#8 RSA 私钥及设备信息后，可自行创建 `~/Library/Application Support/Likeit/netease-openapi.json`。仓库中的 `examples/netease-openapi.example.json` 仅含占位符；不要把真实配置或私钥放进仓库、app 包或聊天记录。

在终端执行以下准备命令，再用本地文本编辑器填写配置；这些命令不申请权限或获取凭据：

```sh
umask 077
mkdir -p "$HOME/Library/Application Support/Likeit"
# 将仓库 examples/netease-openapi.example.json 的内容保存到上述目录的 netease-openapi.json。
# 将你自己的 PKCS#8 PEM 私钥保存到仓库外的私有目录，再填写 privateKeyPath 绝对路径。
# 如果文件原先存在，分别对配置和私钥执行 chmod 600。
```

配置的 `appId`、`accessToken` 必须非空；`privateKeyPath` 是本机私钥文件的绝对路径。私钥应以 `-----BEGIN PRIVATE KEY-----` 开头。`device` 是你为应用提供的非空字符串键值对象，示例字段不代表真实接口所需字段已经验证，请按自己的应用要求填写；产品不生成设备身份，也不读取或仿冒 CLI 身份。配置和私钥各不得超过 64 KiB，必须是普通文件、不能是符号链接，权限不能允许 group 或 other 访问。配置缺失才会使用旧路径；格式、密钥或权限错误会显示配置不可用。

可选 `lyricSource` 只接受 `"word"` 或 `"standard"`，缺省为 `"word"`，示例显式保留该默认值。个人开发者应用若只获普通歌词权限，可设置 `"lyricSource": "standard"`，通过清单和精确歌曲映射直接请求普通歌词，完全跳过逐字接口。`"word"` 保持逐字优先、无同步原文才请求普通歌词；任何一种模式的授权错误都明确失败，不隐式切换来源。null、数字或其他字符串会使配置失败。普通同步歌词不代表逐字高亮，逐字接口权限需单独开通。

退出并重新打开沉浸桌面后配置生效。仍先通过公开完整搜索和详情复验得到数字歌曲 ID，再从官方清单发现搜索命令，通过明确的 `originalId` 与 32 位十六进制 `songId`/`encryptedId` 对应关系确认同一首歌；仅 `data.records` 格式额外接受独立的 32 位十六进制 `id`，并拒绝字段冲突。请求参数采用清单声明的固定值、调用方输入、非 null 默认值的优先级，保留 `false` 和 `0`，不猜测参数或放宽类型与身份校验。不会用播放器 UUID、转换数字 ID 或只看歌名猜测官方 ID。公开候选不完整时仍会拒绝，官方接入不会绕过这项限制。

签名请求只发往 `https://openapi.music.163.com`。会发送你的应用 ID、已有 token（仅需认证的命令）、设备对象、当前曲名和艺人搜索词或已验证的歌曲 ID；私钥只在本机签名，不上传。`word` 模式只显示逐字响应原文 `data.lrc` 的同步行；没有同步原文时才通过清单请求一次普通歌词。`standard` 模式直接使用普通原文歌词，两者均不展示猜测的逐字时间。接口拒绝、映射未确认、清单不受支持、格式错误或超时会明确失败，不静默退回公开歌词。

官方请求不缓存命令清单；成功歌词按当前合法配置的摘要保存在上述本地缓存。不自动登录、刷新 token、读取 Keychain、环境变量或 CLI 缓存；每次请求最多 5 秒和 1 MiB，原歌词流程总计仍最多 15 秒。换曲或退出取消请求并丢弃迟到结果。移走或删除上述 JSON 配置，退出再打开，即恢复公开歌词路径；私钥由你自行保管。

协调会话已取得个人开发者应用的真实清单，并确认该应用的普通歌词接口可用、逐字接口未获授权；这不代表所有应用具有相同权限。产品编译或离线验收不能替代实际桌面显示验证，具体配置与端到端结果由协调会话独立验收。
