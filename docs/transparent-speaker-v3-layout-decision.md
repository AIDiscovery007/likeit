# V3 布局约束决策

2026-10-11，开发者在实施 V3.1 前指出：大驱动单元、全页统一左边线、四条满宽歌词、黑外圈不遮字，四个条件无法同时满足。协调者据此澄清光学排版；233 个冻结文件、BDD 与测试保持原样。这是开始实现前的设计取舍，不是为失败测试修改预期。

保留固定对角驱动单元及接近原稿的直径，不采用永久缩小扬声器、压缩歌词舞台高度的方案。舞台依然约 x4–96%、y15–78%；允许每行有不同的光学起点，取代原设计“全页所有行同一左边线”。

对预先确定的行带，与两只黑外圈的包围盒做相交判断；有相交时选最长的连续安全水平区间，增加 12–20pt 余量，没有相交时使用完整舞台宽。这样上方行从左扬声器右侧起，下方行在右扬声器前收住，其他行横向铺开。使用很小的本地几何计算，不增加通用避障布局系统。

字号、基线和区间只在该页内容／窗口尺寸改变时计算，不随 cue、逐字进度或音频变化。扬声器不跟内容移动。超长句继续有界换行或完整阅读降级；玻璃中心透明，但不强迫文字穿越不透明黑环来制造层次。首个闭环以实际 View 渲染复核，不能以算法存在替代视觉检查。
