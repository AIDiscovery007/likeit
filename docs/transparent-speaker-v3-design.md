# 透明歌词音响：海报排版与分层律动

用户 2026-10-11 明确要求：逐帧拆解原 HTML，恢复更有生命力的 UI 和动效，先写准确设计说明，再由 xhigh 专员精修。基线为 `698c6185113ca3385fb87eed30e82101cf1051df`。本设计基于原稿代码与实际 V2 原生渲染；原稿的帧表是公式采样，不冒充浏览器实帧。

## 设计判断

原稿的主体是「玻璃上的动态歌词海报」：宽幅、凝练的展示字体，四行文字按时间累积出现，透明驱动单元覆盖在字面前景。V2 把它收成 48% 宽的上一句／当前句／下一句，系统黑体把英文撑宽，整句多次换行；两只扬声器整体放大，前后层级和振膜的弹性都被削弱。问题不在动画数量，而在排版尺度、速度曲线、层次差异和连续渲染。

这一轮用四个明确角色组织画面：**文字负责节奏，振膜负责冲击，场景负责纵深，控件负责操作**。经典主题保留原貌。

## 1. 全屏海报构图

- 保留整屏玻璃、黑色窄边、斜向反光、木色底沿。没有 demo 房间底色或外侧留白。
- 同一真实歌词文档按连续四条构成固定页。页内前面已唱的行保留，不降级成灰色小字；当前行入场；尚未到时的行只保留排版空间，不显示、不向辅助功能提前读出。最后一页不足四行按实际条数布局。
- 每页以同一左边线组织，使用约 88–92% 的舞台宽度。预留顶部操作带和底部歌曲／状态带，歌词舞台建议在高度 15–80% 内。把整页视觉重量放在中部偏左，不恢复播放器式居中窄栏。
- 每行分别测量、适配字号，以整页总高度为第二约束。短句大、长句紧，形成疏密和字面尺度变化；同页尺寸只在页内容／窗口尺寸变化时重新计算，逐字进度、频段和每帧动画不能触发字体测量。四行的最终基线在该页第一行出现前已经确定。
- 拉丁字母使用本机已核验存在的 `Impact`（接近原稿 Anton 的高字面、窄字宽、紧密节奏）；CJK 使用系统黑体重字重。保留真实大小写、标点、空格、emoji，不复制 demo 的强制 uppercase。混排不能把中文降成细字。
- 原稿拉丁行高 0.95、CJK 1.0，作为紧凑排版起点。正常句优先一行，超长句使用有界换行，不能缩成不可读的细条或截断内容。极端长句仍需保持完整可读；必要时启用已有类型的滚动阅读降级，不新增独立阅读模式。
- 当前翻译单独置于页下方的稳定次级区域；它跟随当前 cue 更新，不与四行大字争夺同等权重。字号约 16–24pt，最多合理换行，不挤压底部状态。
- 层叠顺序：场景 → 木色底沿 → 歌词 → 透明扬声器 → 玻璃反射／边缘 → 操作控件。透明中心应看得到背后内容；不能用不透明填色假装玻璃。
- 左上／右下的对角构图沿用原稿：驱动单元直径约宽度 17.5%，受高度约束；原稿中心约 x=11.25% 和 72.75%。全屏下允许为控件与可读性微调位置。完整歌词不可被黑色外圈截断；通过行宽、排版起点和驱动单元位置一起消除冲突，不把文字整体缩回 48%。

## 2. 歌词：快速建立字形，缓慢收尾位移

| 元素 | 触发 | 目标行为 |
| --- | --- | --- |
| 当前新行 | 同曲、按顺序进入新的真实 cue | opacity 0→1，220ms，CSS ease 等价曲线 `(0.25,0.1,0.25,1)`；x 从自身字面宽度约 -2.5%→0，500ms，`(0.2,0.8,0.2,1)`。位移可限制到合理像素范围，避免长句扫过半屏。 |
| 同页已出现行 | 进入下一 cue | 保持位置、字号和不透明度，不重新入场，不整体平移。 |
| 当前逐字高亮 | 同 cue 内真实时间推进 | 沿用原 AttributedString 的真实范围，只更新字的明暗；不能重触发整行动画。 |
| 换页 | 顺序从一页末行进入下一页首行 | 新页立即开始入场，旧页淡出约 280–350ms。最多一份旧页快照且不可交互、不可被辅助功能重复读出；采用轻淡退场避免双页同等重量重影。 |
| 首次打开、切回主题、seek／换歌 | 进入新状态 | 直接呈现最新页及应显示的行，旧页立即丢弃；不补播前面行、不排队。 |
| off／暂停／隐藏／失效／减少动态效果 | 门控关闭 | 当帧取消位移和淡出，当前应显示的字完整可读；未来行仍不提前显示。 |

原稿曲线的 60fps 数学采样：100ms 时 opacity≈0.753、位移完成≈0.682；220ms 时 opacity=1、位移完成≈0.923；500ms 位移结束。V2 的线性淡入在 100ms 仅≈0.455，位移≈0.488。新实现应恢复原稿早响应、长收尾的感觉，不增加弹跳、逐字符飞入或模糊文字。

业务仍由真实 cue / position 决定。允许使用局部、可停止的原生显示时间推进一次过渡，解决现有 100ms 播放位置发布导致的视觉阶梯；它不是第二个播放器时钟，不推进歌词、不制造 cue。新输入中断旧动画，退出不等待动画结束。

## 3. 扬声器：外圈稳，振膜动

- 外圈保持黑色橡胶／金属的分层边缘，不做整体呼吸的廉价缩放。参照原稿：外圈最大 scale≈1.012，透明振膜最大≈1.06；两者共用真实低频能量，比例约 1:5。
- 振膜内部同心线、玻璃高光随振膜一起运动；高光亮度可受高频轻微调制。中心保持透光，暗边和内侧高光交代凹面，不增加重度实时毛玻璃采样。
- 现有输入是 30Hz、已平滑的真实 low/mid/high（上升系数 .7、下降 .3）。保留采集与分析管线，不重复做完整包络分析。局部呈现可做短线性插值衔接 30Hz 帧间；不要再用对称慢动画吞掉鼓点。
- 允许把真实低频做简单、有界的感知映射，例如 `min(1, low * 2)`，保证中等能量也看得见位移。固定增益必须在实际截图／帧序列中解释；不使用自动峰值归一化放大噪声，不引入 BPM 或节拍检测。
- 原稿 demo 使用即时 attack、每帧 0.9 衰减（60Hz 半衰≈110ms）；这是感知参考，不把帧率相关算法机械复制到生产。零频段、失效或 gate off 当帧回到基态。

## 4. 场景：慢背景与快节奏分离

背景是低对比的纵深层，不能盖过歌词。参照原稿速度／构图，校正 V2 的过快漂移、过小太阳和规则三频锯齿。

| 场景 | 空间和运动 |
| --- | --- |
| 青瓷 | 三团柔光，x 相位约 0.2 rad/s、y 约 0.17 rad/s，形成慢漂移；低频只令半径约 +7%，不让位置随能量骤跳。 |
| 落日 | 太阳靠右偏下，约 x72%、y60%、r=高度27%；五条由细至粗的水平切口；低频半径约 +8%，静态本身就有明确造型。 |
| 夜航 | 稀疏、确定位置的星点，层次来自不同缓慢相位；底部三条波纹有不同相速，幅度随真实能量增加。保持文字安全区低对比。 |
| 纸页 | 用现有三频段形成连续的条形包络，约 36–40 条、`pow(value,1.4)` 的高度映射；可以在低／中／高锚点间插值，避免 low/mid/high 每三条机械重复。不称完整 FFT。 |

场景显示相位允许在最近可信播放位置之间做局部插值，禁止把播放位置每 100ms 的离散跳变直接当视觉帧率。运动 gate 关闭、频段全部归零或捕获失败时画面精确回静态基态并停掉持续显示更新；音频失败不影响有可信 cue 的歌词入场。没有真实音频时不复制原 HTML 的环境假运动。

## 5. 操作层：轻量、常可达

保留主题、四场景、退出、重试的鼠标／键盘／辅助功能路径。透明主题的操作带使用紧凑字号、薄描边、低对比底板；四场景用小色样和名称传达选择，选中态明确。经典主题的控件不跟着重设计。所有目标有合理点击面积，不做自动隐藏、额外菜单或悬停后才能退出。

顶部和底部不随歌词切换移动。曲名为主、歌手和来源为次；真实错误与重试仍可见，不把技术文案扩大为视觉主体。Cmd+1 / Cmd+2、Esc、Cmd+Q 立即生效。

## 工程边界与取舍

主要改 `native/DesktopView.swift`，只允许 `DesktopSession.swift` 发布当前真实页的最小改动；必要时使用同文件内很小的呈现类型。沿用现有三文件可编译边界。采集、播放器、身份、歌词解析／匹配／缓存、权限、经典主题和依赖保持原行为。

新呈现接口：`DesktopGlassLyricLine: Equatable { cue: DesktopLyricCue, text: String }`，`DesktopModel.glassPage: [DesktopGlassLyricLine] = []`。可信 activeIndex 的页起点为 `(index / 4) * 4`，最多四条，含未来行用于排版；每条携带真实 track/index/start，保留 Unicode。纯文本／纯音乐／首行前／无可信时间／clear／stop 时为空。仅内容改变时发布新页。当前逐字文本和翻译继续用现有字段。

无真实页时沿用诚实的静态歌词／标题／等待状态；纯文本仍可滚动。这些状态不套用四行入场，也不能让上一个真实页残留。

不引入新字体下载、WebView、动画框架、粒子系统、图片资源、第二次采集、通用播放器或主题注册层。每个新增状态必须解释其生命周期；能用系统原生过渡解决时不再维护另一套手写调度。显示更新仅在运动确实活跃时运行。若精确效果需要明显扩大边界，开发者先提供证据和两个具体选项，由协调者决策。
