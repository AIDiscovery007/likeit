# Decimal 输入支持范围

源头Decimal解码修复后原220 tests通过。Standards审查提示有限精度边界，协调者实测JSONDecoder将200.0000000000000000000000000000000000001仍舍入为200。

为避免无限扩张数值能力，官方JSON数值token的mantissa明确限制最多38个十进制数字，超限整份响应作为格式不支持拒绝；JSON字符串内部数字（含歌词/转义引号）不受影响，exponent数字不计入mantissa。既有JSONDecoder继续验证语法及可表示范围，整数200及已有有限精度回归保持。

本补充新增测试，不修改旧断言；开发者只修官方读取边界和重建。主会话负责运行，未触碰真实账号、网络、UI。该限制以fail-closed支持范围阻止静默舍入，不是将错误输入改判成功。

4ec48d7开发前回归：超精度code行为red，38位小数拒绝与含转义引号的长数字歌词保留两项green；含父项共4 tests、2 pass、2 fail。测试驱动编译成功。
