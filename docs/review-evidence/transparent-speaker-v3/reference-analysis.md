## 静态画面决定动效的分量

HTML 62–133、198–205：场景 z0 → 木色底沿 z1 → 歌词 z2 → 驱动单元 z3 → 玻璃反光 z5。歌词透过膜片，叠加暗边、同心环和高光，建立前后关系。V2 先画扬声器再画歌词，且两者基本避开，丢失透镜关系。

HTML 91–104、352–360：文字区域 92%W×86%H，左起4%，上起6%；每页至多四行，以实际字宽分别 fit，再按总高统一收缩。英文 Anton/Impact、行高0.95，CJK黑体900、行高1。V2为48%宽窄栏、上一句／当前句／下一句，固定字号再缩小；配色基本一致，字体与尺度才是主要差异。

1920×1080同尺度下，原稿文字宽1766px、左边77px；V2文字宽922px、左边422px。原稿四个等高英文行的字号上限约244px，V2当前行字号起点156px。原稿透明单元直径336px，V2约302px。

HTML 74–88：背景160°、反光112°；两道不等宽硬边高光、1px内缘、40px内侧暗角。木色底沿用 multiply。V2把背景与反光都改成角到角渐变，普通叠色底沿，缺少内侧暗角，玻璃质感变平。

## 设计优先级

先恢复宽幅字面、四行累积、原曲线和稳定基线；再做振膜与外圈的相对运动；最后校正场景构图／相速、玻璃材质和操作层权重。新设计的边界、参数与验收以 `docs/transparent-speaker-v3-design.md` 为准。
