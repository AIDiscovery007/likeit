# R2 重复文本的逐词定位

Spec独立review在固定提交98f4773复现：`<p begin="1" end="5">go <span begin="3" end="4">go</span></p>`，2秒时错误把第一处无时间go调暗，而实际未开始的第二处go仍是默认亮色。原因是绘制阶段按文本首次子串搜索，未保存解析时的原文位置。此缺陷违反C01未到时间的词不高亮及原文保留要求。

修实现：解析时为每个主词记录可准确映射到完整原文的范围；绘制直接使用该范围，不能靠重复词字符串猜测。保留原冻结构造接口，必要新增字段提供兼容默认值。无可信范围不能冒认另一个匹配；所有原始文字与空白继续完整显示。需考虑UTF-16与Swift字符索引差异，中文/Unicode不可错位。

下列新增合成测试先在错误实现确认红灯，原51项与R1六项及清单均不变。协调者拥有测试；开发者只修产品。
