# 沉浸音乐桌面：视觉与交互方向

依据用户提供的 [MORROR ART A2](https://www.future-mirror.com/morrartA2.html) 页面（2026-10-11 实际浏览）：透明振膜、悬浮双扬声器、大字视觉歌词、音乐成为空间中的视觉主体。仅借鉴这些构成原则，不使用其商标、产品照片或宣传素材。

## 一次进入，一次退出

保留现有 `likeit` / Like Current Track 无界面收藏命令及 `like` 搜索。新增 Raycast `music-desktop` 视图命令，标题 `Likeit`，列表提供“沉浸模式”和“收藏当前歌曲”。进入沉浸模式才打开独立原生全屏窗口；浏览 Raycast 列表不请求音频权限、不启动采集。收藏菜单复用现有命令。

桌面覆盖启动时当前显示器，不铺满所有显示器，不修改壁纸、不挪动原有窗口。全屏内右上角常驻“退出 · Esc”，有清晰点击区域与键盘焦点；Esc、点击退出、Cmd+Q 都立即结束桌面。退出不等待动画、不暂停音乐。若桌面仍是前台，恢复进入前仍存在的 app；用户已切换到其他 app 时，不抢回焦点。

## 一套完整的透明音响主题

- 以近黑和深蓝灰为底，低对比的半透明玻璃边缘营造透明面板深度，保留文字的稳定暗色底。透明音响风格不等同于把其他 app 内容透出来。
- 两个大尺寸同心音膜位于左右两侧，细金属环、柔和高光和少量刻度表现硬件质感；中间留出完整歌词安全区。不得用产品照片贴满屏幕代替实现。
- 当前歌词作为全屏主视觉，居中、最多三行、约 64–104 pt 自适应；上/下一句以较小字号和较低对比辅助，边缘不遮挡正文。遇到长句、中英混排和窗口比例变化，缩字号或换行，不能截断核心歌词。
- 左下角只放曲名、艺人和轻量播放进度；状态说明短而真实。无歌词时以歌曲信息作为主视觉，并明确“暂无可用歌词”或具体原因；不展示示例歌词。
- 退出按钮与简短状态提示具备可读对比度，不依赖鼠标悬停才能发现。

## 动效的因果关系

真实音频的低频能量驱动音膜的轻微位移/缩放，中高频驱动环形细节亮度；幅度有上限，文字保持稳定。安静、暂停、音频不可用时，能量平滑归零，不能保留伪随机节拍。首版承诺真实音频响应，不宣称精确 BPM 或每个鼓点识别。

歌词按真实播放位置选择当前行，正常推进可以短距离/透明度过渡；拖动或换曲立即切换目标，旧歌词不继续排队。入口、退出不加装饰性等待。刷新目标 30 fps，暂停/不可见时降低刷新并停止不需要的采集。

沉浸桌面使用单独的“沉浸桌面动效”三模式设置：跟随系统 / 始终播放 / 关闭，默认跟随系统；收藏彩带的现有设置继续只控制收藏反馈。关闭或跟随系统且开启“减少动态效果”时，保留静态音响、歌词和进度，不启动音频采集。始终播放只覆盖 Likeit 桌面的动效选择，不改 macOS 偏好。

## 必须用真实界面验收

在实际屏幕检查透明音响质感、双侧布局、歌词可读性、长句和中英混排、三种模式、退出/焦点、首次权限提示、拒绝后静态可用和再次进入。自动化模型测试、编译成功和窗口元数据不能替代这些视觉证据。
