# 透明音响主题

Likeit 保留原有「经典音响」，新增「透明音响」。首次打开仍显示经典音响。

## 打开与切换

在 Raycast 打开 Likeit，选择「沉浸模式」并回车，会沿用上次使用的主题。Action 菜单中的「打开经典音响」「打开透明音响」可以直接指定主题，并记住这次选择。

桌面顶部的「音响主题」可即时切换两种外观，也可按 Cmd+1 切到经典、Cmd+2 切到透明；菜单栏「音响主题」列有快捷键。透明音响顶部可选「青瓷」「落日」「夜航」「纸页」；初始场景为青瓷。切回经典音响不会丢失透明场景，下次打开也会恢复。

主题与场景只保存在原生桌面的本地偏好中，没有另一份 Raycast 主题设置。缺失或损坏的主题偏好回落经典音响，场景回落青瓷。

透明音响的玻璃本体铺满窗口，适应当前屏幕比例；黑色窄边框、木色底沿和对角透明扬声器保留。主题、场景、退出及歌曲状态直接叠在玻璃上，没有 demo 的外围底色或缩小展示框。

## 歌词、律动与退出

两种主题共用当前歌曲、歌词、播放进度和音频采集。切换外观不会播放、暂停、切歌或重新匹配当前来源的歌词。「收藏当前歌曲」入口保持原样。

透明音响把有可信时间的歌词每四条组成一页：已唱行保留大字，当前行出现，未来行只保留排版空间。拉丁字母使用本机 Impact，中文及其他字形使用系统重黑体；保留原始大小写、空格和 Unicode，不把歌词强制转成大写。各行围绕两只固定扬声器排版，字号和基线在同页内保持不变。极长行保持至少 24pt，并可在行带内滚动阅读；未同步全文和静态标题使用不穿过外圈的固定阅读区域。当前翻译在页下方单独显示，浅色场景使用深色逐字高亮。纯音乐、无歌词、正在匹配、来源错误和进度不可用等状态继续按实际结果显示，不填入演示内容。

动效允许且顺序进入新的真实 cue 时，当前行按原稿曲线快速显形、缓慢归位：220ms ease 淡入、500ms 小幅向右滑入，位移不超过 18pt。显示帧在这一次过渡内局部插值，不推进业务歌词时间；换页时最多一份旧页轻淡退出，320ms 后移除。翻译即时跟随当前行更新。逐字高亮继续按真实字时间推进，同一行的播放位置更新不会反复触发整行效果。快进、回退和换歌直接跟随最新行，不排队补播；刚切入透明主题直接显示当前歌词。无同步时间的全文、纯音乐和未知进度保持静态可读。

顺序入场以同次歌词计算发布的位置、单调采样时刻和播放速率为证据，不使用界面观察时刻判断。只有速率相同且大于零、样本间隔不超过 500ms、进度增量与速率对应的预计增量相差不超过 5ms 时，才允许连续入场；缺少样本、变速或可辨认的跳变会直接显示最新内容并取消旧过渡。5ms 是数值与来源微小校正的容差，源端没有独立 seek 标识，容差内的极小变化无法与正常推进可靠区分。

扬声器和场景只响应既有 30Hz 采集得到的真实低、中、高频，显示端只用约 33ms 的短线性插值连接相邻输入。低频采用固定的 `min(1, low × 2)` 感知增益：例如 low=0.25 时，外圈放大 0.6%、透明振膜放大 3%；最大幅度分别是 1.2% 和 6%。没有自动峰值归一化或额外包络分析，高频只轻微调亮膜片高光。

青瓷光斑以约 31–37 秒周期慢漂移，低频只改变半径；落日在右下保留五道切口，低频令日轮最多放大 8%；夜航使用不同相速的星光与三条底部波纹；纸页用 40 根柱在三个真实频段之间连续插值，按 1.4 次幂显示高度，不是完整 FFT 频谱。场景相位只在最新可信播放位置后局部插值最多 100ms；没有音频能量时全部立即回到静态基态并停止持续显示更新，不生成节拍。

音频采集失败只停止扬声器和场景响应；可信歌词时钟仍可驱动行与逐字效果。暂停、来源失效、窗口不可见、动效关闭，以及「跟随系统」下开启减少动态效果时，非必要运动停止，歌词立即完整可读；「始终播放」沿用现有覆盖系统动效偏好的规则。可恢复的音频故障仍显示「重试音频」。桌面动效在 Raycast 偏好中设置。

退出按钮、Esc 和 Cmd+Q 沿用原退出链路，释放资源并按原规则返回之前的应用。主题使用系统选择控件，场景使用有名称和选中语义的原生按钮，支持键盘及辅助功能操作。

## 集成说明

原生 URL 的 `theme=classic` / `theme=glass` 可显式选主题；省略 `theme` 保留当前或已存选择，非法值回落经典。仅切换主题的 URL 省略 `mode` / `lyricsSource` 时保留现值；显式歌词来源与当前相同不会重新加载 session。

主题仅使用系统 SwiftUI、系统字体和现有 model/session/audio，不新增依赖、网络请求或权限。已有歌词来源、音频授权及采集限制继续适用。歌词与场景复用已有可信位置和音频输入，不新增播放器时钟；没有演示音乐、BPM、上传或歌词编辑功能。

集成者合并全部歌词和主题源码后，须重新运行 `python3 scripts/build-desktop.py`，一并更新 app 和 `DESKTOP-BUILD.json`，再安排安装验收。开发分支不交付旧基线构建的二进制，不覆盖用户安装包。

本次开发仅完成离线构建、类型及 lint 检查。四场景截图、窗口比例与长歌词、真实音频、重复切换、键盘与退出焦点等验收由协调会话执行；离线构建通过不代表实机验收通过。
