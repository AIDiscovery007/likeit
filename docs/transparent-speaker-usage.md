# 透明音响主题

Likeit 保留原有「经典音响」，新增「透明音响」。首次打开仍显示经典音响。

## 打开与切换

在 Raycast 打开 Likeit，选择「沉浸模式」并回车，会沿用上次使用的主题。Action 菜单中的「打开经典音响」「打开透明音响」可以直接指定主题，并记住这次选择。

桌面顶部的「音响主题」可即时切换两种外观，也可按 Cmd+1 切到经典、Cmd+2 切到透明；菜单栏「音响主题」列有快捷键。透明音响顶部可选「青瓷」「落日」「夜航」「纸页」；初始场景为青瓷。切回经典音响不会丢失透明场景，下次打开也会恢复。

主题与场景只保存在原生桌面的本地偏好中，没有另一份 Raycast 主题设置。缺失或损坏的主题偏好回落经典音响，场景回落青瓷。

透明音响的玻璃本体铺满窗口，适应当前屏幕比例；黑色窄边框、木色底沿和对角透明扬声器保留。主题、场景、退出及歌曲状态直接叠在玻璃上，没有 demo 的外围底色或缩小展示框。

## 歌词、律动与退出

两种主题共用当前歌曲、歌词、播放进度和音频采集。切换外观不会播放、暂停、切歌或重新匹配当前来源的歌词。「收藏当前歌曲」入口保持原样。

透明音响保留歌词原始大小写和 Unicode 文字，支持逐行、逐字、翻译及可滚动的未同步纯文本。浅色场景使用深色逐字高亮。纯音乐、无歌词、正在匹配、来源错误和进度不可用等状态继续按实际结果显示，不填入演示内容。

动效允许且有可信播放位置时，新歌词行与翻译按真实行身份入场：约 220ms 淡入、500ms 小幅向右滑入。逐字高亮继续按真实字时间推进，同一行的播放位置更新不会反复触发整行效果。快进、回退和换歌直接跟随最新行，不排队补播；刚切入透明主题直接显示当前歌词。无同步时间的全文、纯音乐和未知进度保持静态可读。

扬声器和场景只响应既有采集得到的真实低、中、高频：青瓷光斑漂移与呼吸，落日条纹轻微缩放，夜航星光与横向波纹，纸页条形响应。纸页重复展示三个频段，不是完整 FFT 频谱。需要相位时只使用可信播放位置；没有音频能量时全部回到静态基态，不生成节拍。

音频采集失败只停止扬声器和场景响应；可信歌词时钟仍可驱动行与逐字效果。暂停、来源失效、窗口不可见、动效关闭，以及「跟随系统」下开启减少动态效果时，非必要运动停止，歌词立即完整可读；「始终播放」沿用现有覆盖系统动效偏好的规则。可恢复的音频故障仍显示「重试音频」。桌面动效在 Raycast 偏好中设置。

退出按钮、Esc 和 Cmd+Q 沿用原退出链路，释放资源并按原规则返回之前的应用。主题和场景使用系统选择控件，支持键盘及辅助功能操作。

## 集成说明

原生 URL 的 `theme=classic` / `theme=glass` 可显式选主题；省略 `theme` 保留当前或已存选择，非法值回落经典。仅切换主题的 URL 省略 `mode` / `lyricsSource` 时保留现值；显式歌词来源与当前相同不会重新加载 session。

主题仅使用系统 SwiftUI、系统字体和现有 model/session/audio，不新增依赖、网络请求或权限。已有歌词来源、音频授权及采集限制继续适用。歌词与场景复用已有可信位置和音频输入，不新增播放器时钟；没有演示音乐、BPM、上传或歌词编辑功能。

集成者合并全部歌词和主题源码后，须重新运行 `python3 scripts/build-desktop.py`，一并更新 app 和 `DESKTOP-BUILD.json`，再安排安装验收。开发分支不交付旧基线构建的二进制，不覆盖用户安装包。

本次开发仅完成离线构建、类型及 lint 检查。四场景截图、窗口比例与长歌词、真实音频、重复切换、键盘与退出焦点等验收由协调会话执行；离线构建通过不代表实机验收通过。
